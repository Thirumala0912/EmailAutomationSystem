# Email Automation and Ticket Management System using UiPath

## Project Overview

This project automates email ticket management using UiPath and Excel automation. The workflow reads email details, generates unique ticket IDs, and stores ticket information into an Excel sheet automatically.

## Features

* Automated ticket generation
* Outlook email automation
* Excel data storage
* Workflow automation using UiPath
* RPA-based ticket management

## Technologies Used

* UiPath Studio
* Microsoft Outlook
* Microsoft Excel
* RPA Automation

## Workflow

1. Read Outlook emails
2. Generate Ticket ID
3. Create ticket records
4. Store ticket details in Excel

## Output

The automation stores:

* Ticket ID
* Sender
* Subject
* Status
* Date

inside `Tickets.xlsx`.
